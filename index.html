执行摘要

本页对比客户夏米（org 14006）在 2024.11–2025.10（上期）与 2025.11–2026.10（本期）两个完整 12 个月窗口（各 365 天）的客服健康指标（全平台汇总，共 47 项）。两期均为完整年度（已逐日探针确认本期 10-31 有数据），直接同比，无需日均折算。总体呈「人工接待大幅收缩、机器人承接比例显著提升，订单不降反升；跟单助手三件套全面铺开成为最大亮点；但响应时长明显退坡」的格局。 量增价微降，付款质量同步改善：订单数 31.5万 → 34.7万（+10.0%）；订单金额 ¥3203.6万 → ¥3397.4万（+6.1%）；单均金额 ¥101.7 → ¥98.0（-3.6%）——增长主要来自单量。非 COD 订单付款率 89.82% → 93.63%（+3.81pp）；非乐聊接待占比 5.53% → 3.03%（-2.50pp），接待仍以乐聊为主。 接待收缩三成、订单不降反升，机器人在撑盘：接待买家 10,376 → 7,112（-31.5%），接待覆盖率 3.29% → 2.05%，但接待转化率 13.20% → 13.64%（+0.44pp）——用更少的接待承接了更多的订单。结构上人工接待近乎减半：7,102 → 3,499（-50.7%），机器人接待占比 54.47% → 72.09%（+17.62pp）；人工接待转化率 10.59% → 10.95%，机器人 16.26% → 15.35%（仍高于人工约 4.4pp）；响应买家问题数 22,404 → 13,731（-38.7%）——服务触达变薄，但订单与金额都涨了，被砍掉的大多是低意向接待。 响应退坡是人工收缩最直接的代价：人工平均响应 2h44m → 3h52m（+67min / +41.0%），买家咨询平均等待接待 7h07m → 9h25m（+139min / +32.5%）；1 分钟内响应率 32.22% → 23.58%（-8.64pp）、3 分钟内 49.36% → 36.67%（-12.69pp），60 分钟内被接待率仅 69.38%——近三成咨询 1 小时内无人承接。 跟单助手三件套全面铺开，是本年度最大亮点：物流呵护订单占比 53.23% → 95.41%（+42.18pp），未呵护订单 102,915 → 11,950 张（剩余未呵护的弃单率 31.83%，是呵护后 10.63% 的 3 倍）；催付订单 4,325 → 12,878（+197.8%），催付后付款率 27.01% → 36.19%（+9.18pp）；弃单沟通率 7.24% → 38.09%（+30.85pp），增量几乎全部来自机器人（沟通 1,077 → 16,517 单），机器人沟通后挽回率 34.52% 与人工 33.33% 相当、显著高于未沟通订单的 26.69%——自动化沟通在本客户真实有效。最终弃单率 12.12% → 11.29%（-0.84pp），弃单挽回 12,989 → 14,252 单，被挽回金额 ¥148.3万 → ¥160.4万。

结论与建议

主线是「机器人承接更多、人工更聚焦，量的账是划算的」。接待买家 -31.5%、人工接待 -50.7%、响应买家问题数 -38.7%，换来订单 （+10.0%）、金额 （+6.1%）、最终弃单率 （-0.84pp）、非 COD 付款率 （+3.81pp）；弃单沟通率从 7.24% 提到 38.09%，机器人沟通后挽回率 34.52% 不输人工 33.33%——与「机器人挽回效果差」的常见情形相反，本客户的机器人沟通链路已经跑通，这也是敢继续收缩人力的底气。 代价记在响应上，还有两个小尾巴。3,499 人次人工接待（-50.7%）对应 34.7万 订单，平均响应 3h52m、等待接待 9h25m、1 分钟内响应率 23.58%（-8.64pp）。尾巴一：未呵护订单只剩 11,950 张，但弃单率 31.83%，是呵护后（10.63%）的 3 倍——剩下的是最难啃、也最值得啃的部分。尾巴二：未催付订单 2,509 张、付款率 33.40%，而催付后付款率 36.19%——催付覆盖还有最后一段没铺满。 建议下一周期：① 响应补位不加人——机器人接待转化率 15.35% 已显著高于人工 10.95%，弃单沟通也已验证有效，建议把售前首触进一步交给机器人（当前占比 72.09%），人工聚焦高意向与售后，排队超 30 分钟的会话自动改派与升级，把 1 分钟内响应率（现 23.58%）拉回 30% 以上；② 补齐最后的呵护覆盖——未呵护 11,950 张、弃单率 31.83%，按店铺排查未触发原因，按 21.2pp 的差距估算，全部补齐约可再少弃约 2,500 单 / 年；③ 催付扩量与时机复盘——催付占比已 83.69%，剩 2,509 张未催付；弃单原因第一的「Unpaid Order」5,810 张（本期），建议按未付款时长分层（如 2h / 12h / 24h 三档）测试触达时机，把催付后付款率 36.19% 再往上抬。
